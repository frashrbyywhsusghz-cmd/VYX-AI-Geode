# Changelog

## 0.3.0 - Live input tracking

- Count gameplay physics frames from the player update loop.
- Record Player 1 and Player 2 jump presses.
- Display each recorded input frame and the gap from the previous press.
- Show the four most recent jump inputs in the gameplay HUD.
- Add separate settings for the frame counter and jump-input tracker.
- Remove the misleading hardcoded +/-2F label.

## 0.2.0 - Geometry Dash 2.2081 compatibility

- Pin Geode SDK 5.11.2 for Geometry Dash 2.2081.
- Keep the Android64 build target.

## 0.1.0 - Project foundation

- Add initial Geode mod structure for Android.
- Add VYX AI entry button to the main menu.
- Add Android64 GitHub Actions build workflow.
